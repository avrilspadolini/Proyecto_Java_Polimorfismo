# Proyecto Java - Polimorfismo

Proyecto realizado para la facultad utilizando Java y programación orientada a objetos.

## Conceptos utilizados

- Herencia
- Polimorfismo
- Clases abstractas
- Redefinición de métodos
- ArrayList
- Composición y asociación

## Descripción

Proyecto basado en la gestión de diferentes tipos de drones, con características y comportamientos propios.
